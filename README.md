## About the Project

SaBoNa is a native Android mobile application inspired by the popular Serbian quiz show *Slagalica*.

The application was developed as a team project, focusing on mobile application development, interactive gameplay, and creating an engaging user experience through quiz-based challenges.

## Getting Started

### Prerequisites

Before running the application, make sure you have the following installed:

* Android Studio
* Android SDK 26 or higher
* Java 11 or higher
* Android Emulator or a physical Android device

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/NFunduk/e2-ma-tim07-2026.git
```

**2. Open the project in Android Studio**

* Launch Android Studio.
* Select `File → Open`.
* Navigate to the cloned repository.
* Select the project folder.

**3. Sync the project**

Wait for Gradle to download the required dependencies and complete synchronization.

**4. Run the application**

* Connect an Android device or start an Android Emulator.
* Select the target device in Android Studio.
* Click `Run` to build and launch the application.
